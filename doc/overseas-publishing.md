# YouTube / TikTok 自动发布接入指南

海外渠道走官方 OAuth 授权，不使用 Cookie。你需要先到开发者后台注册应用、拿到
Client ID / Secret（TikTok 叫 Client Key / Secret），再回到工作台完成一次授权。

所有令牌只保存在本机（按运营账号隔离，位于该账号数据目录的 `oauth-tokens.json`），
界面上只显示「已授权」状态，不回显明文。授权窗口、令牌交换与文件上传都会自动套用
「连接设置 → 网络代理」里配置的代理。

---

## 一、YouTube

### 1. 创建 Google Cloud 项目并启用接口

1. 打开 https://console.cloud.google.com/ ，用你要发布视频的 Google 账号登录。
2. 顶部项目下拉 →「新建项目」，随便取个名字（如 `wmc-workstation`）→ 创建。
3. 左侧「API 和服务 → 库」，搜索 **YouTube Data API v3** → 启用。

### 2. 配置 OAuth 同意屏幕

1. 「API 和服务 → OAuth 同意屏幕」。
2. 用户类型选「外部」→ 填应用名称、你的邮箱 → 保存。
3. 作用域可以留空（授权时会按请求自动带 `youtube.upload`）。
4. 测试用户里加上你自己的 Google 账号（Testing 模式下只有测试用户可以授权）。

> **重要**：测试（Testing）模式下拿到的刷新令牌 **7 天后失效**，到期就要重新授权。
> 个人长期使用请在同意屏幕页把发布状态切到 **「正式版 / In production」**。
> 未通过验证的应用也能用，只是首次授权会看到一个「Google 尚未验证此应用」的警告页，
> 点「高级 → 继续前往」即可。

### 3. 创建 OAuth 客户端

1. 「API 和服务 → 凭据」→「创建凭据 → OAuth 客户端 ID」。
2. 应用类型选 **「桌面应用」**，名称随意 → 创建。
3. 记下 **客户端 ID** 和 **客户端密码**。

桌面应用类型的回调地址允许任意本机回环端口，因此不需要往 Google 后台填回调地址，
工作台显示的 `http://127.0.0.1:5180/api/oauth/YouTube/callback` 直接可用。

### 4. 在工作台完成连接

1. 「连接设置 → 海外渠道 → YouTube」，把 **Client ID / Client Secret** 粘进去，点「保存」。
2. 点「授权连接」→ 弹出独立浏览器窗口 → 选择账号并同意。
3. 看到「授权成功」页面即完成，回到工作台，卡片会显示「已授权」。

可选字段：

- **默认可见性**：`unlisted`（默认，拿到链接可分享、搜索不可见）/ `public` / `private`。
- **默认分类ID**：默认 `22`（人物与博客）；常用分类见
  https://developers.google.com/youtube/v3/docs/videoCategories/list 。

### 5. 配额

YouTube 每日默认配额 10,000 单位，**每次视频上传约消耗 1600 单位**，即每天约 6 次上传。
超额时任务会失败并提示「每日上传配额已用尽」，次日恢复。

## 二、TikTok

### 1. 注册开发者并创建应用

1. 打开 https://developers.tiktok.com/ ，用你要发布的 TikTok 账号登录并注册为开发者。
2. 「Manage apps → Connect an app」，填应用名称等基础信息。

### 2. 添加产品与权限

1. 在应用里添加 **Login Kit**，平台选 **Desktop**。
2. 添加 **Content Posting API**。
3. 在 Scopes 里勾选：
   - `user.info.basic`（读取昵称，用于显示授权账号）
   - `video.upload`（上传视频到收件箱）

### 3. 注册回调地址

Login Kit 的 **Redirect URI** 填工作台连接卡上显示的回调地址，**必须完全一致**：

```
http://127.0.0.1:5180/api/oauth/TikTok/callback
```

注意：

- 端口必须和工作台实际端口一致（默认 5180；若你用 `--port` 改了端口，这里也要改）。
- 路径末尾 **没有** 斜杠，请与连接卡显示的内容逐字对照。
- 平台类型必须是 Desktop；Web 平台不接受 `http://127.0.0.1` 的地址。

### 4. 在工作台完成连接

1. 「连接设置 → 海外渠道 → TikTok」，填入 **Client Key / Client Secret**，点「保存」。
2. 点「授权连接」→ 在弹出窗口登录并同意授权。
3. 卡片显示「已授权（账号：昵称）」即完成。

### 5. 发布方式：收件箱上传

应用未通过 TikTok 审核时，不能直接公开发布。本工作台使用**收件箱上传**：

- 任务执行后视频会上传到你的 TikTok「收件箱」，任务状态为 **「待核验」**。
- 打开 TikTok App → 通知 / 收件箱 → 选择该视频，补文案、音效、封面后手动点「发布」。
- 完成发布后，可在发布中心手动把任务标记为「已发布」。

这样做的好处是不用等 2–4 周的 Direct Post 审核；缺点是最后一步要在手机上点一下。
未审核应用直接发公开视频只能设为「仅自己可见」，且限制 5 个用户 / 24 小时，所以本工作台
不提供直接公开直发。

## 三、代理

- 「连接设置 → 网络代理」启用后，授权窗口（Chrome `--proxy-server`）、令牌交换、
  视频上传全部走该代理；本机回环地址自动直连，回调页面能正常打开。
- 代理密码错误时，接口会返回「代理认证失败（407）」。
- 不开代理时全部直连，海外网络不可达时会提示连接失败。

## 四、常见问题

**授权窗口没弹出来 / 找不到回调页**

关闭窗口后，把浏览器地址栏里回调页的完整 URL（`http://127.0.0.1:5180/api/oauth/...callback?code=...&state=...`）
复制，粘贴到连接卡的「粘贴地址栏的完整回调 URL」，点「完成授权」同样能拿到令牌。
Google 的授权会话有 10 分钟有效期，超时请重新点「授权连接」。

**提示「授权已失效，请重新授权」**

YouTube：测试模式 7 天过期，或你在 Google 账号里撤销了授权；切到正式版并重新授权。
TikTok：令牌过期或你在 App 里取消了应用授权；重新点「授权连接」。

**令牌存在哪里？会不会上传？**

按账号存放在本机数据目录的 `oauth-tokens.json`，与 Cookie 一样明文落盘、读取时掩码，
不会回传到前端，也不会上传任何服务器。「断开授权」会删除该渠道令牌。

**换账号**

每个运营账号有独立的令牌文件与授权状态；账号 A 授权后切到账号 B，B 会显示「未授权」，
需要单独授权。
